# BoardPlus

سبورة الحصة التفاعلية لكل معلم: المعلم يدخل بحساب Google، والطلاب يدخلون بكود الحصة بدون حسابات.
فكرة وتطوير أ. محمد رجب.

> هذا المشروع منفصل تمامًا عن **ragabboard** (مشروع Firebase مختلف ومستودع GitHub مختلف).

## المكونات

| الملف | وظيفته |
|---|---|
| `public/index.html` | السبورة (المعلم، الطالب، لوحة الإدارة) |
| `public/games.html` | BoardPlus Games (الألعاب داخل السبورة) |
| `public/rt.js` | مكتبة الاتصال اللحظي بالخادم |
| `src/worker.js` | الخادم: Cloudflare Worker + Durable Objects (الغرف والصلاحيات والتخزين) |
| `wrangler.toml` | إعدادات النشر على Cloudflare |
| `dev/` | أدوات التطوير والاختبار المحلي فقط (لا تُنشر) |

- **Cloudflare (مجاني):** يشغّل الموقع والاتصال اللحظي ويخزن بيانات الحصص.
- **Firebase (مجاني):** فقط لتسجيل دخول المعلمين بحساب Google. لا قاعدة بيانات فيه.

## خطوات التشغيل (مرة واحدة، حوالي 20 دقيقة)

### 1) مشروع Firebase جديد لتسجيل الدخول
1. افتح https://console.firebase.google.com ← **Add project** ← سمّه `boardplus` (بدون Google Analytics).
2. من القائمة: **Build ← Authentication ← Get started ← Sign-in method ← Google ← Enable**، واختر بريد الدعم ثم **Save**.
3. **Project settings** (الترس) ← **Your apps** ← أيقونة الويب `</>` ← اسم `boardplus` ← **Register app**.
4. انسخ القيم الأربع: `apiKey` و`authDomain` و`projectId` و`appId`.
5. لاحظ الـ **Project ID** (مثل `boardplus-a1b2c`).

### 2) ضع القيم في الملفات
- في `public/index.html` ابحث عن `const FIREBASE_CONFIG =` واملأ القيم الأربع.
- في `wrangler.toml` غيّر `FIREBASE_PROJECT_ID = "boardplus-xxxxx"` إلى الـ Project ID.

> هذه القيم ليست أسرارًا، ومن الطبيعي أن تكون في ملف عام.

### 3) ارفع المشروع على GitHub
- أنشئ مستودعًا **جديدًا** اسمه `boardplus` (لا تستخدم مستودع ragabboard)، وارفع فيه كل الملفات.

### 4) انشر على Cloudflare
1. أنشئ حسابًا مجانيًا على https://dash.cloudflare.com.
2. **Workers & Pages ← Create ← Import a repository** ← اربط GitHub واختر `boardplus` ← **Deploy**.
3. بعد النشر يظهر الرابط، مثل: `https://boardplus.<اسمك>.workers.dev`.
4. افتح الـ Worker ← **Settings ← Variables and Secrets ← Add**:
   - النوع: **Secret**
   - الاسم: `ADMIN_EMAILS`
   - القيمة: بريدك على Gmail (ولأكثر من مدير افصل بينها بفاصلة).
   - ثم **Deploy**.

### 5) اسمح للرابط في Firebase
Firebase ← **Authentication ← Settings ← Authorized domains ← Add domain** ← أضف `boardplus.<اسمك>.workers.dev`
(وأي دومين خاص تربطه لاحقًا).

### 6) جرّب
1. افتح الرابط ← **ابدأ كمعلم مجانًا** ← سجّل بحسابك (المدير). سيظهر لك زر **لوحة الإدارة**.
2. من جوال آخر ادخل كطالب بكود الحصة.

أي تعديل ترفعه بعد ذلك على GitHub ينشره Cloudflare تلقائيًا.

## لوحة الإدارة
- إحصائيات: عدد المعلمين، حصص اليوم والشهر، وكل الحصص.
- خيار **«المعلمون الجدد يحتاجون موافقتي»**:
  - مغلق (الافتراضي): أي معلم يسجّل يبدأ فورًا.
  - مفتوح: المعلم الجديد ينتظر تفعيلك.
- إيقاف معلم، تفعيله، أو حذفه.
- رؤية من في حصة الآن وكودها.

## حدود الخطة المجانية (تقريبًا)
- مناسبة لمئات المعلمين وحصص كثيرة متزامنة يوميًا.
- الحد اليومي الأهم هو 100 ألف طلب في اليوم على Durable Objects. كل 20 رسالة لحظية تُحسب طلبًا واحدًا.
- إذا تجاوزته يتوقف الموقع حتى بداية اليوم التالي (بتوقيت UTC). لا تُخصم أي أموال.
- تُحذف بيانات الحصة والألعاب تلقائيًا بعد 12 ساعة من بدايتها.
- بنوك الأسئلة الخاصة بكل معلم تبقى محفوظة.

## الذكاء الاصطناعي
- توليد الأسئلة يستخدم مفتاح Gemini المجاني الخاص بكل معلم.
- المفتاح يُحفظ في متصفح المعلم فقط، ولا يُرفع للخادم ولا يوضع في الملفات.
